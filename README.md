# Clearbase Transport Services

Static website prepared for GitHub Pages.

## Publish

1. Create a public GitHub repository named `clearbase-transport-services`.
2. Upload the files and `assets` folder from this package to the repository root, or push this directory with Git.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. The site will appear at `https://mcmillianchinoda.github.io/clearbase-transport-services/` after the Pages build finishes.

The shipment enquiry opens WhatsApp with a prepared message. The site does not collect or store submissions on GitHub.
